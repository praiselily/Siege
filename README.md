# Siege

A Windows-based automatic screenshare tool, mostly intended for minecraft.

Siege attaches to a running Minecraft client and sweeps the machine for signs
of cheating or tampering, then presents everything it finds.

It is not a replacement for manual pc checks and does not come close to actual
commercial scanners but it can assist and will be maintained as I have time.

## Requirements

- Windows 10 or 11 (64-bit)
- Administrator privileges (required to read the system state the scan relies on)

## Access

This tool is **not open source** and keys are not publicly distributed. Access is
limited to boosters on my discord server. 

discord.gg/pz2g4Zs3Gc

## Disclaimer

Siege is an aid for manual review, not an automated verdict. Findings should
always be trusted or taken as the definitive truth.
